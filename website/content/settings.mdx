## Settings: install, configure, keep control

Use the published Windows package for the application. This website is the
wiki, not the installer or a browser control panel for your machine.

<ReleaseInstall />

### Tools and workspace configuration

In Studio, choose the output folder, screenshot folder and card size.
Keep FFmpeg, FFprobe, Whisper and optional model paths explicit. The
`saveSettings`, `setSize` and `openOutput` actions are local operations;
changing the wiki's Card size changes only the reading surface.

### Agents, SDK and privacy

Grant agents the smallest necessary directory scope. Separate capability
discovery from readiness, read-only HTTP tools from stdio writes, and
build-time validation from deployment authorization. Keep signing keys,
model caches, recordings and personal configuration out of GitHub assets.

Read [Agent Plugin security boundaries](/yumlog/docs/AGENT-PLUGIN/),
[SDK/framework prerequisites](/yumlog/docs/SDK-FRAMEWORK/) and
[media presets](/yumlog/docs/MEDIA-PRESETS/).
