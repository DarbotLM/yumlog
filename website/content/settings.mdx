### Instructions: verify and install the ZIP

Run the following commands yourself in a working directory with room for
the extracted suite. `downloads`, `yumlog-package`, and `yumlog-source`
should be new directories.

```powershell
gh release download v0.7.1 --repo DarbotLM/yumlog --dir .\downloads `
  --pattern 'Yumlog-0.7.1-win-x64.zip' --pattern 'Yumlog-0.7.1-win-x64.zip.sha256'
$zip = '.\downloads\Yumlog-0.7.1-win-x64.zip'
$expected = ((Get-Content "$zip.sha256" -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash $zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'Package checksum mismatch' }
Expand-Archive -LiteralPath $zip -DestinationPath .\yumlog-package

gh repo clone DarbotLM/yumlog .\yumlog-source -- --branch v0.7.1 --single-branch
.\yumlog-source\launchers\Install-YumlogProduction.ps1 `
  -PackagePath .\yumlog-package -ExpectedVersion 0.7.1
```

The [versioned production installer](https://github.com/DarbotLM/yumlog/blob/v0.7.1/launchers/Install-YumlogProduction.ps1)
uses the package manifest, creates user-local versioned binaries and normal
integration shortcuts, and preserves valid existing native configuration.
Use its `-NoUserIntegration` switch if you do not want user integration.
Do not overwrite a working installation directory manually.

### MSIX alternative

Inspect the package identity, signature and publisher before installation.
Do not disable Windows signature checks or trust a certificate just to make
an installation succeed. The
[versioned MSIX installer](https://github.com/DarbotLM/yumlog/blob/v0.7.1/launchers/Install-YumlogNativeMsix.ps1)
documents package checks and revision handling. The published MSIX does not
include the full suite of separate Paperboy/APIM/Widget Studio executables.

### Tools and workspace configuration

In Studio, choose the output folder, screenshot folder and card size.
Keep FFmpeg, FFprobe, Whisper and optional model paths explicit. The
`saveSettings`, `setSize` and `openOutput` actions are local operations;
changing the wiki's Card size changes only the reading surface.

### Agents, SDK and privacy

Grant agents the smallest necessary directory scope. Separate capability
discovery from readiness, read-only HTTP tools from stdio writes, and
build-time validation from deployment authorization. Keep signing keys,
model caches, recordings and personal configuration out of GitHub assets.

Read [Agent Plugin security boundaries](/yumlog/docs/AGENT-PLUGIN/),
[SDK/framework prerequisites](/yumlog/docs/SDK-FRAMEWORK/) and
[media presets](/yumlog/docs/MEDIA-PRESETS/).
